Hello World: Gaussian Toy Example
=================================

``examples/helloworld_gaussian_toy/`` is a simple helloworld-type example of the semi-parametric SBI approach: a five-dimensional Gaussian toy dataset, two density-ratio networks, an unbinned NSBI workspace for semi-parametric model and a standard signal-strength fit. It uses the training and model APIs directly, with no configuration files, so it is the quickest way to see what each piece does.

Dataset
-------

``generate_distributions.py`` samples signal and background from independent Gaussians in ``x1`` to ``x5`` and writes parquet files to ``dataframes/``. The signal comes at three nodes of a morphing parameter, as generated by Malin Horstmann for another example. The fit in this example uses only the ``signal_10`` as the signal. Per-event weights are scaled so the total yields do not depend on the number of generated events.

.. code-block:: shell

   python generate_distributions.py             # 2M background, 1M signal per node
   python generate_distributions.py --n_sig 5_000_000

Notebooks
---------

1. ``1_visualize_data.ipynb`` — signal and background distributions of the five features.
2. ``2a_SigvsRef_training.ipynb`` — trains :math:`r_\text{sig}(x) = p_\text{sig}(x) / p_\text{ref}(x)` and runs the calibration and reweighting closure tests.
3. ``2b_BkgvsRef_training.ipynb`` — the same for :math:`r_\text{bkg}(x)`.
4. ``3_parameter_fitting.ipynb`` — evaluates both networks on the observed dataset, writes the workspace and fits :math:`\mu`.

The reference is an equal mixture of signal and background, each carrying half of the reference weight, so both ratios are bounded by 2. See :doc:`density_ratio_training` for why.

Workspace
---------

The workspace is written in notebook 3 and shows the minimal unbinned structure the statistical model needs: one channel with the expected yields per sample, and an ``observations`` entry with the observed yield, the per-event weights and the density ratios evaluated on the observed events.

.. code-block:: python

   {
       "channels": [{
           "name": "SR",
           "type": "unbinned",
           "samples": [
               {"name": "signal",     "data": [yield_sig], "modifiers": [{"name": "mu", "type": "normfactor"}]},
               {"name": "background", "data": [yield_bkg], "modifiers": []},
           ],
       }],
       "observations": [{
           "name": "SR",
           "data": [yield_obs],
           "weights": "<path/to>/weights.npy",
           "ratios": {"signal": "<path/to>/ratio_sig.npy", "background": "<path/to>/ratio_bkg.npy"},
       }],
       "measurements": [...],
       "version": "1.0.0",
   }

The observed dataset in the example is the Monte Carlo expectation dataset generated at :math:`\mu = 1`, so the fit recovers :math:`\hat\mu = 1` up to the noise of the trained ratios. The notebook ends with the workspace layout for adding ``normplusshape`` systematic modifiers, which is what the :doc:`FAIR example <workflow>` builds automatically from the configuration file.
